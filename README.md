# VK Swiss — Maquette e-commerce (refonte 2026)

Maquette HTML multipage du nouveau site e-commerce de VK Swiss (compléments ayurvédiques au ghee suisse), réalisée par l'Agence Cerf à Lunettes, à reconstruire en WordPress + Elementor Pro + WooCommerce (voir `GUIDE-WORDPRESS.md`).

- Pages générées par `build/build.py` à partir de `build/data.py` (`python3 build/build.py`, `STAGING=0` pour retirer le noindex).
- Panier, conseiller (arbre de décision) et mobile « application » : `assets/js/app.js` + `assets/js/data.js`.
- Vidéo hero : Runway (12 s) · Images : ChatGPT · Packshots et logo : VK Swiss.
